СПРАВКА о наличии у Государственного бюджетного профессионального образовательного учреждения Московской области «Электростальский колледж» специальных условий для получения образования обучающимися с ограниченными возможностями здоровья

В ГБПОУ «Электростальский колледж» созданы условия для получения образования обучающимися с ограниченными возможностями здоровья и обучающимися с инвалидностью. Присутствует доступная среда, достаточная для обеспечения возможности беспрепятственного доступа обучающихся с ограниченными возможностями здоровья в корпуса ГБПОУ «Электростальский колледж». Обучающиеся с инвалидностью и обучающиеся с ограниченными возможностями здоровья, как и все остальные обучающиеся, обучаются в установленные конкретной образовательной программой сроки. При необходимости, с учетом особенностей и образовательных потребностей конкретных обучающихся, разрабатываются индивидуальные учебные планы.

По каждой дисциплине образовательных программ разработаны рабочие программы, включающие методические рекомендации по самостоятельному освоению курсов. На основе индивидуального подхода организуется практика обучающихся с инвалидностью и обучающихся с ограниченными возможностями здоровья. Обучающиеся с инвалидностью и обучающиеся с ограниченными возможностями здоровья могут обучаться с применением элементов дистанционных образовательных технологий. При необходимости удельный вес занятий с применением дистанционных технологий для данной категории обучающихся может быть увеличен.

Для освоения дисциплины «Физическая культура» в ГБПОУ «Электростальский колледж» установлен особый порядок. Обучающимся с инвалидностью предлагаются письменные задания (написания рефератов). По желанию обучающегося ему разрабатывается специальный комплекс упражнений для самостоятельного физического совершенствования. Для обучающихся с ограниченными возможностями здоровья проводятся занятия с доступной физической нагрузкой, учитывающей особенности каждого. В ГБПОУ «Электростальский колледж» имеется электронная образовательная среда, размещаются лекции, тесты, примеры задач и практических заданий, полезная для обучающихся информация. Для лиц с инвалидностью и лиц с ОВЗ оказываются услуги сурдопереводчика, тьютора, социального педагога, психолога. Помещения колледжа оснащены цветовыми желтыми лентами, звонками вызова дежурного персонала, информационными табличками Брайля, цифровым электронным информационным стендом.
